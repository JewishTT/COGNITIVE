# Запуск Gods Eye View

Один Vite-проект в корне совмещает **фронтенд** и **«бэкенд» для данных**
(встроенные server-side прокси OpenSky / CelesTrak / TomTom / FIRMS / и т.д. —
отдельный процесс не нужен). Две вкладки платформы тянут внешние сервисы:
ОСИНТ (Flowsint, `:5001`) и Фабрика (Postiz, `:4007` через Docker).

## Минимальный запуск (фронт + живые данные)

```bash
npm run dev          # vite на http://localhost:4173/
```

Открой:

- `http://localhost:4173/` — оболочка платформы (вкладки Глобус / ОСИНТ / Фабрика)
- `http://localhost:4173/globe` — сам 3D-глобус (его и встраивает вкладка «Глобус»)

Требуется `GOOGLE_MAPS_API_KEY` в `.env` (иначе `scripts/dev-fresh.sh` остановится).
Остальные ключи (OpenAI, OpenSky, AISStream, Cesium ion, TomTom, FIRMS) — опциональны;
без них соответствующие слои просто пустые/симулированные. Альтернатива `npm run dev`:
`./scripts/dev-fresh.sh` (тот же сервер + диагностика ключей, только для bash).

## Фабрика (Postiz, Docker)

```bash
npm run dev:factory        # docker compose up -d  → Postiz на :4007
npm run dev:factory:down   # остановить стек
```

Без этого вкладка «Фабрика» показывает заглушку «Postiz не запущен».

## ОСИНТ (Flowsint)

Внешний сервис — **его нет в этом репозитории**. Нужно запустить отдельный
экземпляр Flowsint так, чтобы он отвечал на `http://<host>:5173`
(iframe грузит его напрямую, а прокси `/osint` в `vite.config.js` тоже смотрит
на `:5173`). Без него вкладка «ОСИНТ» показывает заглушку «Flowsint не запущен»,
но TDA-анализ в соседней вкладке работает и без бэкенда (кнопка «Демо»).

## Разработка платформы (опционально)

Если правишь Vue-код платформы отдельно, подними её dev-сервер на `:5180`,
который проксирует `/globe` → `:4173`:

```bash
npm run dev:globe      # только глобус + оболочка на :4173
npm run dev:platform   # только Vue-платформа на :5180 (нужен dev:globe рядом)
# или всё сразу в одном терминале:
npm run dev:all
```

## Сборка / превью

```bash
npm run build    # корень: dist/ с index.html (глобус) и platform.html (оболочка)
npm run preview  # статика из dist/ (глобус на /globe, оболочка на /)
```

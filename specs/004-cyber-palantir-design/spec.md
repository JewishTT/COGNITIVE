# СПЕКА 004: Cyber‑Palantir Design System — глобальный апгрейд

## Проблема

Платформа после частичного редизайна (ShellLayout + Dashboard) всё ещё содержит
разрозненные стили в экранах OSINT (AnalyticsTab, SettingsTab, TdaTab,
UiFlowsintTab, widgets). Цель — **максимальный** апгрейд всей платформы к единому
дизайн-языку: баланс между киберпанком (неоновые каймы, grid, LED, glow) и
строгим Palantir (плотная сетка, моноширинные цифры, сухие панели).

## Дизайн-принципы (constitution)

1. **Каркас = строгий Palantir.** Тёмные плоские панели, острые/почти-прямые углы
   (radius ≤ 4px), тонкие бордеры, высокая плотность данных.
2. **Акценты = киберпанк дозированно.** Неон действует только на границах
   (top/bottom), LED-статусах, иконках и ключевых CTA. Без заливок и градиентов
   по всему блоку.
3. **Моноширинный цифровой слой.** Все значения/статистика/код — JetBrains Mono,
   uppercase, letter-spacing. Прописной текст — Inter.
4. **Единые токены.** Одна палитра `--accent`, `--accent-2`, `--surface-*`,
   `--glow-*` во всех компонентах. Никаких локальных магических цветов.

# flowsint-enrichers — TheBigBrother

Enricher в слое оркестрации Flowsint. По архитектуре пайплайна Gods Eye View
TheBigBrother стоит **после первичного сбора** (BBOT / theHarvester / Amass / Shodan),
который наполняет граф сущностями `Username` и `Email`, и **перед TDA-слоем**,
который строит симплициальные комплексы над обогащённым графом.

```
Семя ─▶ BBOT/theHarvester (Этап 1: широкий сбор) ─▶ TheBigBrother (Этап 2: глубокий профайлинг)
                                                   │
                                                   ▼
                              Flowsint Core + Neo4j (Этап 3: обогащение/индексация)
                                                   │
                                                   ▼
                              TDA-Enricher (Этап 4: топологический анализ)
                                                   │
                                                   ▼
                              Flowsint UI / платформа Gods Eye View (Этап 5: визуализация)
```

## Компоненты

- `tools/osint/thebigbrother_tool.py` — низкоуровневая обёртка над CLI `thebigbrother`.
  Если бинарь недоступен, возвращает детерминированный мок, чтобы модуль можно
  импортировать и тестировать без внешних зависимостей.
- `enrichers/person/thebigbrother_enricher.py` — принимает `Username`/`Email`,
  запускает тул, создаёт в графе `SocialMediaProfile` / `Email` / `Phone` / гео-узлы
  и связи с экспертными весами (`platform_confidence`).

## Место вызова в пайплайне

1. Сначала Enricher BBOT добавляет в граф `Username` / `Email`.
2. Затем Enricher TheBigBrother обрабатывает эти сущности (триггер в Flowsint
   настраивается на запуск после первого).
3. Параллельно могут идти Maigret / Social-Analyzer / Adler — результаты
   объединяются в графе.
4. Когда все Enricher'ы завершились, TDA-Enricher анализирует насыщенный граф.

## Влияние на TDA

- Больше узлов/связей → плотнее граф, TDA выявляет скрытые циклы (β₁),
  указывающие на единую личность across платформ.
- Вес ребра = экспертная уверенность платформы (LinkedIn > Twitter > … > Pastebin),
  поэтому TDA строит **взвешенные симплициальные комплексы**: слабые связи
  отсекаются порогом, и топология «проявляется» по мере роста порога веса.
